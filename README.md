# Filmivalija - rühm Edutu

Meie projekt on veebileht, mis aitab kasutajal valida filmi meeleolu järgi.
Veebilehel on plaanis tutvustada umbes 30 filmi.
Avalehel kuvatakse filmide valik.
Küsimustiku lehel saab kasutaja vastata oma meeleolu puudutavatele küsimustele.
Vastuste põhjal pakub veebileht kasutajale sobiva meeleoluga juhusliku filmi.
Rühma liikmed on Artur Golovko, Marion Poljakov ja Anna Angelika Rebane.
Artur vastutab GitHubi repositooriumi, kahe lehe HTML-i, JavaScripti efektide ja koodi kontrollimise eest.
Marion vastutab kujunduse visandi, esimese CSS-faili, vahearuande ja veebilehe üleslaadimise eest.
Angelika vastutab HTML-i baasfailide, ühise CSS-i ja sisu loomise eest.

## Koostööreeglid

- Osaleme rühma kohtumistel.
- Täidame ülesanded kokkulepitud tähtajaks.
- Oleme kursis tehtud töö ja tähtaegadega.
- Aitame vajadusel üksteist.
- Väljendame eriarvamusi ja kuulame teisi.
- Kirjutame otsused ja ülesannete muudatused ühisesse vestlusesse.
